# G-UNIT Trading Systems | ATLAS

G-UNIT is a personal software-development project exploring modular trading-system architecture, market intelligence, data validation, risk management, and execution infrastructure.

> **Project status:** In active development. Features described as planned or under development are not necessarily implemented.

## Project Overview

ATLAS is designed as a modular platform for market-data ingestion, market analysis, trading workflows, risk controls, and execution integrations. The project emphasizes clear interfaces, testable components, and documented development milestones.

FORGE is a separate development-tooling initiative and is not part of ATLAS's market-intelligence responsibilities.

## Development Focus

- Python application structure and modular architecture
- Market-data provider and integration interfaces
- Data validation, timestamps, symbols, and price handling
- Automated tests and maintainable code
- Git-based version control and technical documentation
- Future integration work subject to design, testing, and verification

## Technology and Tools

- Python
- Git and GitHub
- pytest
- Ruff, Black, and mypy (development tooling)
- Windows, PowerShell, and Ubuntu/WSL development environments
